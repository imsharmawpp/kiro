# kiro workspace

Personal workspace configured to operate Kiro as a senior engineer for writing, planning, debugging, and animated-website work.

The behaviour is defined in `.kiro/steering/`:

- [`senior-engineer.md`](.kiro/steering/senior-engineer.md) — Karpathy's four principles + the three iron laws (TDD, root-cause-first, verification-before-claims).
- [`writing-and-proofreading.md`](.kiro/steering/writing-and-proofreading.md) — voice, structure, proofreading checklist, commit/PR templates.
- [`planning-and-bug-fixing.md`](.kiro/steering/planning-and-bug-fixing.md) — brainstorm → spec → plan → TDD flow, plus the four-phase debugging protocol.
- [`animated-website-playbook.md`](.kiro/steering/animated-website-playbook.md) — default stack, animation principles, perf and a11y budgets.

Distilled from:
[obra/superpowers](https://github.com/obra/superpowers),
[affaan-m/everything-claude-code](https://github.com/affaan-m/everything-claude-code),
[multica-ai/andrej-karpathy-skills](https://github.com/multica-ai/andrej-karpathy-skills),
[ruvnet/ruflo](https://github.com/ruvnet/ruflo),
[pablo-mano/Obsidian-CLI-skill](https://github.com/pablo-mano/Obsidian-CLI-skill),
[nexu-io/open-design](https://github.com/nexu-io/open-design).

Steering files load automatically into every Kiro session in this workspace. To change behaviour, edit them.
